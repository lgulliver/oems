# Agent instructions

This repository owns a language-neutral draft specification. Clio application code belongs in a separate repository.

Read README.md, GOVERNANCE.md, VERSIONING.md and the relevant RFC before changing semantics. Preserve draft status. Distinguish research attribution from OEMS policy. Do not silently choose licences, invent accreditation or issue unsupported conformance claims.

For semantic changes, update specification text, schemas, examples and conformance cases together through the RFC process. Use fictional data. Keep schema structure validation distinct from semantic and calculation validation.

Astra and Claude may author and review bounded tasks using the same documented contract. Handoffs list changed behaviour, affected files, checks actually run and remaining questions. Routine documentation does not require unnecessary tests; changes to schemas or expected calculations require relevant validation.
