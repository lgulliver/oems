# Licensing decision pending

The project intends to publish an openly implementable specification, reusable schemas and test fixtures. The maintainer has not selected or granted an open licence for these materials yet. Public repository visibility alone does not establish those permissions.

Before a specification release, record explicit terms for specification prose, schemas, fixtures and any helper code, along with contribution terms. Patent and trademark questions require a separate decision; a software licence does not automatically resolve them.

Do not interpret this note as a licence grant or a contributor agreement. Until the decision is recorded, the repository is a public working draft and must not be advertised as a released open standard.
